## 🚀 Featured Work

### 🟢 Built from scratch — Offline-first Census Platform

A **mobile-first data-collection platform** for large-scale field operations:
a React Native/Expo app that lets field workers collect data **fully offline**,
a React admin dashboard for configuration and analysis, and a Node.js/TypeScript
REST API that orchestrates the entire workflow.

- **Offline-first sync** — data collected in the field (expo-sqlite) syncs in
  batches when connectivity returns (background tasks).
- **Precise geolocation** — a location-accurate app: geo-registered points are
  validated server-side against defined polygons (contains-checks), so location
  accuracy and integrity are a core focus.
- **Dynamic form engine** — configurable questionnaire templates via an EAV
  model → flexible schemas **without DB migrations**.
- **Role-driven web dashboard** — each role gets its own tooling: define form
  templates, create censuses from them, and analyze geo-points on the interactive
  map.
- **RBAC with geographic scoping** — 4 access tiers, enforced on every operation.
- **Cryptographic audit trail** — append-only log with SHA-256 hash chaining,
  sealed by a background worker.
- **Deploy** — nginx + PM2 cluster + PgBouncer + Redis + PostgreSQL, environment-
  parameterized for test/stage/prod, with secrets rotation, preflight checks and
  backups.

> I own *everything*: the API, the mobile app, the web dashboard, the test
> suite (unit + integration + contract + e2e), and the production infrastructure.

<br/>

### 🟡 Rescued & modernized — Aging Enterprise Systems

I take **legacy systems written by others** — undocumented, monolithic, fragile —
and bring them back to life: I read the code, reverse-engineer what no one
documented, and modernize it safely.

- **Reverse-engineering undocumented frameworks** — old Struts apps built on
  an in-house framework with zero documentation; I read it from source and
  extend it safely.
- **Enterprise integrations** — SAML 2.0 / SSO via reverse-proxy header auth,
  LDAP, institutional backends, JasperReports & PDF generation.
- **Modernization path** — Java EE / JSF / PrimeFaces → containerized WARs on
  modern servers → Spring Boot; plus Go microservices for cross-cutting needs.
- **Old frontends, rebuilt** — Angular 8 and React 19 dashboards with proper
  test coverage (Vitest + Playwright).

> Comfortable anywhere in the JVM ecosystem, and fluent at bridging
> 20-year-old systems into modern, containerized, documented deploys.
