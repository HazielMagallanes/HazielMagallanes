## 🚀 Trabajo destacado

### 🟢 Construido desde cero — Plataforma de Censo Offline-first

Una **plataforma de recolección de datos mobile-first** para operaciones de
campo a gran escala: una app React Native/Expo que permite recolectar datos de
forma **totalmente offline**, un dashboard web de administración para
configuración y análisis, y una API REST Node.js/TypeScript que orquesta todo
el flujo de trabajo.

- **Sincronización offline-first** — los datos recolectados en campo
  (expo-sqlite) sincronizan por lotes cuando vuelve la conectividad (tareas en
  background).
- **Geolocalización precisa** — una app precisa: los puntos geo-registrados se
  validan en el servidor contra polígonos definidos (chequeos de contención), de
  modo que la precisión e integridad de la ubicación son un foco central.
- **Motor de formularios dinámicos** — plantillas de cuestionarios configurables
  vía un modelo EAV → esquemas flexibles **sin migraciones de BD**.
- **Dashboard web según rol** — cada rol tiene sus propias herramientas: definir
  plantillas, crear censos a partir de ellas y analizar los puntos geo en el
  mapa interactivo.
- **RBAC con alcance geográfico** — 4 niveles de acceso, aplicados en cada
  operación.
- **Traza de auditoría criptográfica** — log append-only con encadenamiento
  SHA-256, sellado por un worker en background.
- **Deploy** — nginx + cluster PM2 + PgBouncer + Redis + PostgreSQL, parametrizado
  por entorno para test/stage/prod, con rotación de secretos, chequeos preflight
  y backups.

> Me hago cargo de *todo*: la API, la app móvil, el dashboard web, la suite de tests
> (unit + integración + contrato + e2e) y la infraestructura de producción.

<br/>

### 🟡 Rescatados y modernizados — Sistemas Empresariales Legados

Tomó sistemas **legados escritos por otros** — no documentados, monolíticos,
frágiles — y los revivo: leo el código, hago ingeniería inversa de lo que nadie
documentó y lo modernizo de forma segura.

- **Ingeniería inversa de frameworks no documentados** — viejas apps Struts
  basadas en un framework interno con cero documentación; las leo desde el
  código fuente y las extiendo de forma segura.
- **Integraciones empresariales** — SAML 2.0 / SSO vía auth por headers de
  reverse-proxy, LDAP, backends institucionales, generación de reportes
  JasperReports y PDF.
- **Camino de modernización** — Java EE / JSF / PrimeFaces → WARs containerizados
  en servidores modernos → Spring Boot; más microservicios Go para necesidades
  transversales.
- **Frontends viejos, reconstruidos** — dashboards Angular 8 y React 19 con
  cobertura de tests adecuada (Vitest + Playwright).

> Cómodo en todo el ecosistema JVM, y fluido para conectar sistemas con 20 años
> a deploys modernos, containerizados y documentados.
